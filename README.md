A quick implementation for [Self-Compressing Neural Networks](https://arxiv.org/abs/2301.13142). It's a demonstration only, so I don't save quantized models and only simulate the behavior in the forward pass.

### How to run
1. Install [uv](https://docs.astral.sh/uv/) if not installed.
2. Clone the repo and enter it.
3. Update your Python environment with `uv sync`.
4. Run the code with `uv run python main.py`
